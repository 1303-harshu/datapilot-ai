# DataPilot AI

AI-Powered Data & Decision Intelligence Platform

## Overview

DataPilot is an end-to-end platform that combines data analytics,
machine learning, and AI to help users explore datasets,
generate insights, build predictive models, and interact with
their data using natural language.

## Planned Features

- Data upload and management
- Automated EDA
- Interactive analytics dashboards
- Machine learning predictions
- Model comparison
- Explainable AI using SHAP
- AI-powered data assistant
- Natural language to SQL
- User authentication
- Deployment

## Tech Stack

- Python
- Pandas
- SQL
- Scikit-learn
- XGBoost
- SHAP
- FastAPI
- React
- PostgreSQL
- LLM API
- Docker
